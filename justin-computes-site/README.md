# Justin Computes Static Site

This is a starter multi-page static website for justincomputes.com.

## Pages

- `index.html` - Home
- `about.html` - About
- `resume.html` - Resume/accomplishments
- `projects.html` - Projects
- `setup.html` - Current setup/specs
- `gear.html` - Amazon affiliate/gear links
- `contact.html` - Contact/social links

## What to edit first

Search the files for these placeholders:

- `YOUR_HANDLE`
- `YOUR_PROFILE`
- `YOUR_EMAIL@example.com`
- `YOUR_AFFILIATE_LINK`

Replace them with your real Instagram, TikTok, LinkedIn, email, and Amazon links.

## Deployment path

1. Create a GitHub repository named `justincomputes-site`.
2. Upload these files to the repository.
3. Create a Cloudflare account if needed.
4. Go to Cloudflare Pages.
5. Connect to GitHub.
6. Select the `justincomputes-site` repo.
7. For build settings:
   - Framework preset: None
   - Build command: leave blank
   - Output directory: `/`
8. Deploy.
9. Add your custom domain in Cloudflare Pages.
10. Update DNS at Porkbun based on Cloudflare's instructions.
